# AutoFTBQ Agent Mod

AutoFTBQ Studio 的游戏内前端。当前原型支持 Minecraft 1.20.1、Forge 和 FTB Quests 2001.4.22。

alpha.14 增加暂停/继续，并修复整本同步后编辑权限丢失。需要同时更新 Studio 后端以启用工具步骤实时提交；旧版后端没有暂停接口。暂停不丢弃已提交修改，撤销仍仅支持最近一批。以下旧版本说明作为历史记录保留。

当前 alpha.12 修复批内对象索引及同步时面板消失，并包含 alpha.11 的 SNBT 与回滚修复。客户端/服务端须同时更新。开发时运行 `gradlew.bat build strictSnbtSmoke questIndexSmoke` 可验证真实 Mojang 解析器、FTBQ 对象索引和面板状态；此烟测不替代游戏内撤销与故障回滚验收。

## 开发环境

- Java 17（必须；不要使用 Java 21 启动当前 Gradle 8.1.1 构建）
- Minecraft 1.20.1
- Forge 47.2.19

## 构建

```powershell
cd game-mod
.\gradlew.bat build
```

输出位于 `game-mod/build/libs`。

## 当前操作

1. 先启动 AutoFTBQ Studio。
2. 在安装了 FTB Quests 的 1.20.1 Forge 客户端中安装本 Mod。
3. 进入世界并打开 FTBQ，选择一个或多个任务。
4. 在 FTBQ 编辑器右上角点击 `Agent`，或按 `G` 展开原生编辑器内的右侧面板。
5. 直接在面板输入请求；当前章节、正在查看的任务和多选任务会自动同步，无需手工选择上下文。
6. 面板会显示共享对话、排队/分析进度、工作历史和修改记录；修改通过检查后自动应用，可以取消请求或撤回最后一次写入。
7. Studio 连接状态下可点击“在工作台编辑游戏任务书”，编辑后点击“同步到游戏”；游戏端会自动领取并应用工作台事务。

Agent 面板是 FTBQ `QuestScreen` 的原生 FTB Library 子面板，不会再打开一套独立任务书编辑器。Studio 只负责模型、索引、安全策略和 Agent 后端。它可以读取选中任务详情，批量搜索或校验游戏内实时物品、方块和实体注册表，并按精确物品 ID 查询当前世界加载的配方。即使没有多选任务，也会自动同步正在查看的任务和章节。长回答可以滚轮浏览或一键复制。

Agent 会生成易读的结构化事务并自动应用；应用前会重新同步客户端与服务端的任务书内容指纹，服务器再次验证 FTBQ TeamData 编辑权限、字段、对象和物品 ID，再以可回滚批次执行。FTBQ 自带的 `PersistedData` 会在整本同步重建界面时恢复章节、缩放、滚动位置和多选任务，面板展开状态也会保留。工作台同步支持章节、任务、条件、奖励、章节组、奖励表、删除操作和当前整合包加载的自定义类型，并以原始 SNBT 保留未知字段；游戏命令仍未开放。服务器事务、Studio 结果回报和断线后的待处理工作台修改均可安全重试。

已通过 Java 17 干净构建和 Forge 开发客户端主菜单启动烟测。服务端权限、真实世界写入、失败回滚与撤销仍必须先在备份后的测试世界中交互验证，再用于正式任务书。
