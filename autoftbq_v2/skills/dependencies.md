# 任务连线与分层布局

1. 创建两个以上的连续主线任务时，必须同时建立依赖；不要把一组互不相连的节点称为完整流程。
2. 连续流程优先使用 `add_quest_chain`，它会一次创建任务、顺序连线并在达到行宽后换到下一层。
3. 已有任务需要分支或汇合时，先读取任务 ID，再使用 `apply_dependency_plan` 一次提交依赖方案。
4. 主线过长时按 4 至 6 个节点换行，但依赖仍应跨行连续，不要靠画面位置暗示前置关系。
5. 除章节入口或明确可选任务外，每个主线节点至少应有一个前置；分支可以共享同一个前置。
6. 完成后必须重新读取章节并调用 `validate_project`。缺少连线、任务数量不足或未验证时，不得回复“已完成”。
